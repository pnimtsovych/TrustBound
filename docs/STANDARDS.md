# Стандарти та стандартизація

## На чому стоїть TrustBound
- **NIST SP 800-207 — Zero Trust Architecture.** 7 принципів. TrustBound закриває найскладніші: доступ per-session (№3), динамічна політика зі станом пристрою й середовища (№4), безперервний моніторинг постури (№5), примусова авторизація перед кожним доступом (№6).
- **DoD Zero Trust Strategy (2022).** 7 стовпів. TrustBound підсилює **Device** (TPM-атестація), **User** (авт. + присутність), **Data** (шифрування, прив'язане до присутності), **Network/Environment** (геозона + UWB), **Visibility** (журнал без підробки).
- **TCG TPM 2.0** — апаратний корінь ідентичності та attestation.
- **IEEE 802.15.4z / FiRa** — захищене UWB-ranging (STS, час прольоту).
- **Galileo OSNMA** — автентифікація навігаційного сигналу.
- **Криптографія** з FIPS 140-3-валідованих модулів (AES-GCM, SHA-256, HKDF) + Ed25519; **TLS 1.3**, **FIDO2/WebAuthn**.

## Правові аспекти
- **Персональні дані:** локація й присутність — персональні дані → у ЄС **GDPR** (правова підстава, мінімізація, **DPIA**); в Україні — ЗУ «Про захист персональних даних».
- **Держсистеми (Україна):** ЗУ «Про захист інформації в ІКС»; вимоги **Держспецзв'язку**; побудова й атестація **КСЗІ**; **НД ТЗІ**.
- **Оцінка продукту:** **Common Criteria (ISO/IEC 15408)**; криптомодуль — **FIPS 140-3**.
- **Приватність працівників і експортний контроль** (подвійне використання) — врахувати.

## Як стандартизувати в компанії
1. **Пілот + оцінка ризиків** (за потреби DPIA).
2. **Внутрішній стандарт/політика** — «Контроль доступу за присутністю»: сфера, ролі, зони, TTL ключів, fail-secure та аварійні (правило двох осіб) процедури.
3. **Інтеграція в ISMS (ISO/IEC 27001)** — як контроль, що посилює контролі ISO/IEC 27002 (доступ, фізична безпека, криптографія).
4. **Регламенти + навчання** — реєстрація пристроїв, обслуговування маяків, реагування на інциденти.
5. **Аудит → сертифікація** — внутрішній аудит, далі ISO 27001 (ISMS), Common Criteria (продукт), FIPS 140-3 (крипто).
6. **Держсектор/оборона України** — узгодження з Держспецзв'язку, побудова й атестація КСЗІ; для НАТО — STANAG / вимоги замовника.

> Інформаційний огляд, не юридична консультація — для реальної сертифікації залучайте фахівців з комплаєнсу та юриста.
